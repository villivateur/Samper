# Param List

## System

## Wifi

- 0x10: enable

## Motor

- 0x100: enable
- 0x110: velocity
- 0x120: forward component
- 0x121: left component
- 0x122: right component
- 0x123: back component

## Status LED

- 0x200: frequecy
- 0x201: duty

## Beep

- 0x210: frequecy
- 0x211: duty

## Head light

- 0x220: On/Off

## Battery monitor

- 0x300: ADC voltage(mV)
- 0x301: Battery voltage(mV)
